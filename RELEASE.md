# Release

This repository is set up for GitHub Releases.

## Release asset URL pattern

Use this format for a downloadable release asset:

https://github.com/peterbuyck1-collab/FMCSADATA/releases/download/<tag>/<filename>

Example:

https://github.com/peterbuyck1-collab/FMCSADATA/releases/download/v1.0.0/FMCSADATA.zip

## Suggested release format

- Version: v1.0.0
- Tag: v1.0.0
- Title: FMCSADATA v1.0.0
- Description:
  - Initial release
  - Data package included
  - Release notes and validation summary

## Example release notes

### FMCSADATA v1.0.0

- Initial public release
- Data package included in the release asset
- Ready for download from the GitHub Releases page

## Notes

- Upload the final archive as a release asset (for example, `FMCSADATA.zip`).
- Keep the tag name aligned with the version number.
- Update this file as new releases are published.
